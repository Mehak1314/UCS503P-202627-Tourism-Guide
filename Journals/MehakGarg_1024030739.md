# Weekly Work Journal
## LLM-Based Tourist Guide Website

This project is being developed by a team of three members. The project focuses on developing an **LLM-based Tourist Guide website** that can help tourists explore destinations, plan trips, and receive personalized travel assistance.

The project is divided into different modules including frontend development, backend development, database management, and AI/LLM integration.

---

### Work Done

#### Team Work
- Finalized the idea of developing an **LLM-based Tourist Guide website**.
- Discussed the main objective of the project: helping tourists explore destinations and plan their trips using an AI-powered assistant.
- Identified the major features required for the website:
  - User registration and login
  - Tourist destination information
  - Trip planning
  - AI chatbot
  - Personalized travel recommendations
- Discussed the overall system architecture and workflow.
- Divided the project into three major areas:
  - Frontend development

- Planned the major frontend pages and components.
